v2.1 업데이트 · Spark 무료 서버
옷장 → 캐릭터에서 여러 친구를 동시에 골라요. 친구별 옷 기억 + 각자 크기 50~250%. 아이폰/웹은 앱 안에서만 함께 걸어요. Android는 다른 앱 위에도 띄울 수 있어요.
호감도·레벨은 친구마다 따로 올라가요. 프로필에서 친구의 응원 횟수/알림을 설정해요 (9~22시 KST).
상단 친구 → 코드로 친구 요청, 1:1 채팅. 내 사진 배경·말풍선 색/불투명도·창 이동/크기 조절/모서리에 접기.
계정 복구·친구·실제 전송은 Firebase 무료 Spark로 동작해요 (카드·Cloud Functions 불필요). 익명 로그인·Firestore·보안 규칙이 준비되면 앱이 자동으로 연결해요. 준비 중이거나 오프라인이면 게임과 백업 코드는 그대로 가능해요.
사진 배경은 기기에만 저장해요. 채팅 창은 앱 안에서만 떠요.

🍎 아이폰에서 설치하기

⚠️ 꼭 Safari(사파리)로 열어 주세요! 카카오톡·인스타그램 안에서 링크를 누르면 열리는 화면(앱 안 브라우저)에서는 홈 화면에 추가가 안 돼요.
  1. 카톡으로 받은 링크를 길게 눌러 복사하고, Safari를 열어 주소창에 붙여 넣어요.
    (카톡에서 링크를 열었다면 오른쪽 아래 ⋯ 또는 나침반 버튼 → "Safari로 열기"를 눌러도 돼요)
    주소: 이 페이지 주소
  2. 화면 아래(또는 위)에 있는 공유 버튼 (네모에서 화살표가 위로 나온 모양 ⬆️)을 눌러요.
  3. 목록을 아래로 내려서 "홈 화면에 추가"를 누르고, 오른쪽 위 "추가"를 눌러요.
    (안 보이면 목록 맨 아래 "작업 편집"에서 추가할 수 있어요)
  4. 이제 홈 화면에 생긴 🌱 놀자! 먼작귀 아이콘으로 열어요. 앱처럼 전체 화면으로 열리고, 인터넷이 없어도 돼요.
  5. 처음 열면 닉네임과 비밀번호(숫자 4자리)를 정하고 캐릭터를 골라요. 끝! 🎉
🔑 백업 코드 꼭 만들어 두기!
아이폰은 이 게임을 오래(몇 주) 안 열면 기록이 지워질 수 있어요. 가끔 메뉴 → 프로필 → "백업 코드 만들고 복사"를 누르고, 카톡 "나에게 보내기"나 메모에 붙여 두세요. 기록이 사라지면 로그인 화면의 "백업 코드로 불러오기"에 붙여 넣으면 그대로 돌아와요. (비밀번호도 그대로예요)
💡 홈 화면 아이콘으로 연 것과 Safari에서 연 것은 기록이 따로 저장돼요. 항상 아이콘으로 열어 주세요.
💡 "화면 친구"(앱을 꺼도 화면 위를 걸어 다니는 기능)는 아이폰에서는 안 돼요. 안드로이드 앱 전용이에요.

🤖 안드로이드에서 설치하기

  1. 아래 버튼을 눌러 앱 파일(APK)을 받아요. (카톡으로 받은 .apk 파일을 눌러도 돼요) 📦 앱 파일 받기 (APK)
  2. 다 받아지면 알림이나 내 파일 → 다운로드에서 파일을 눌러요.
  3. "출처를 알 수 없는 앱" 경고가 나오면 설정 → "이 출처 허용"을 켜고 뒤로 가기를 눌러요.
    (삼성: 설정 → 애플리케이션 → 특별한 접근 → 출처를 알 수 없는 앱 설치 → 카카오톡/내 파일/Chrome 허용)
  4. "설치"를 눌러요. Play 프로텍트 창이 뜨면 "세부정보 더보기" → "무시하고 설치"를 눌러요. (우리끼리 만든 앱이라 그래요)
  5. 설치가 끝나면 열기! 닉네임·비밀번호를 정하고 캐릭터를 골라요.
